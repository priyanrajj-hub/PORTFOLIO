## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/priyanrajj-hub/PORTFOLIO.git
cd PORTFOLIO
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
The optimized production bundle will be output to `./dist/`.

---

## 🌐 Deploy to Vercel (Recommended)

1. Go to [vercel.com/new](https://vercel.com/new).
2. Import the repository `priyanrajj-hub/PORTFOLIO`.
3. Vercel automatically detects the included `vercel.json` and Vite framework configuration.
4. Click **Deploy**.
