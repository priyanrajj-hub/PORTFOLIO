## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/priyanrajj-hub/PORTFOLIO.git
cd PORTFOLIO
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
The optimized production bundle will be output to `./dist/`.

---

## 🌐 Deploy to GitHub Pages

To deploy the production build to your GitHub Pages:

```bash
# Build the project
npm run build

# If using gh-pages branch:
npx gh-pages -d dist
```

Alternatively, configure the included GitHub Actions workflow for automatic deployment upon pushing to `main`.
